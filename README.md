# GCF – modules SCORM

Modules SCORM 1.2 pour la formation Gestionnaire Comptable et Fiscal (GCF, bac +2), adaptés des cours TFE « Comptabiliser la clôture des comptes annuels ».

| Module | Dossier | Zip à importer dans le LMS |
|---|---|---|
| L'affectation du résultat | `affectation-resultat/` | `zips/SCORM_GCF_Affectation_du_resultat.zip` |
| Les emprunts | `emprunts/` | `zips/SCORM_GCF_Les_emprunts.zip` |

Chaque module : cours interactif, exercices auto-corrigés (ordre des lignes libre, dépôt `.xlsx` possible), quiz final (réussite à 70 %).
